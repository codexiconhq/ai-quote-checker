# AI Quote Checker

AI-powered quotation review and comparison app. This is a separate Codexicon product.

## Current status

Initial Flutter UI foundation:
- Home dashboard
- Upload quotation screen placeholder
- Sample analysis results screen

The current results are illustrative only. Document upload, authentication, database storage and AI analysis are not connected yet.

## Technology

- Flutter / Dart
- Supabase (planned: authentication, database and secure file storage)
- OpenAI API (planned: quotation extraction and analysis)

## Run locally

1. Install Flutter SDK and Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

## Roadmap

1. Complete and test the Flutter app shell.
2. Add PDF/image file selection and validation.
3. Set up Supabase authentication and private document storage.
4. Add secure server-side AI analysis.
5. Build quotation history and comparison.
6. Test Android, then prepare iOS support.

Never put private API keys in the Flutter client or commit secrets to GitHub.
